## 数据与指标口径

原始968张图片，966份XML，8类。固定验证172张图、204个标注实例。原图、训练裁剪、增强图、模型权重、Python/CUDA环境及识别历史不随源码发布。请按课程数据授权自行准备数据。

前三代历史指标的候选、阈值与选头设置存在差异，不能将历史 mAP、固定阈值F1和全量图片分歧率直接作严格横向排名。第一代39/966＝4.04%表示与现有XML的图片级分歧，不能当作确认错误率。

第四代mAP：使用固定172张图的19114个低分去重候选，未先按网站0.30显示阈值过滤。每框仅预测一个鸟种，检测分数×分类分数排序，COCOeval八类宏平均。验证集反复用于开发和选模型，不是独立测试成绩。

## 运行说明

这是原E盘工程的代码快照，目录名称和配置保留原项目结构以便追踪。历史脚本包含本机路径，新机器须按各项目README和配置调整数据、环境与权重路径。未打包的上游仓库及环境需自行安装，详见[复现说明](docs/REPRODUCE.md)。不要在没有完成依赖与权重准备时直接运行训练入口。

已准备原始本地工程的机器可双击 `本地鸟类识别网站/启动网站.cmd`，浏览 `http://127.0.0.1:8765`。关闭服务可使用 `停止网站.cmd`。

## 代码来源

本项目基于PaddleDetection、BioCLIP 2、FET-FGVC、DINOv2与RF-DETR开展课程实验。上游代码不整库复制入本仓库，相关版本与许可证由各上游项目维护。本项目的适配、训练脚本、后处理与实验组织不代表提出这些基础模型，也不声称完全复现论文公开数据集成绩。

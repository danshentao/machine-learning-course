## 指标解释

mAP与第四代历史主口径一致：原生低分候选下限0.001，原分数优先IoU≥0.5额外去重，每框只保留一个物种。第一代直接使用其联合检测类别分数；后面三代用检测分×分类top-1分排序。COCOeval以IoU0.5、101点插值和maxDets=100计算八类平均。没有先以0.30或0.50删掉低分框。

整图完全正确率：检测分数严格大于0.30后，按类别与IoU≥0.5一对一匹配，全部标注目标都匹配且无多余预测框的图片数/172。漏鸟、多框、分错类别或定位不足均会导致该图不计为完全正确。

已匹配框分类准确率：先忽略物种按检测分数与IoU≥0.5进行一对一几何匹配，再计算物种正确数/几何匹配数。没有检出的鸟不进入此分母，因此必须结合无框图、召回和F1理解。

这些都是与现有XML的一致性指标。固定验证集已经反复用于开发，历史训练清单与预算不完全一致，不能据此宣称独立测试准确率或公平的同预算算法优劣。

第二代两个分类器分别报告，没有将其误写为投票融合。原PPT的历史AP与本轮统一后的结果可能不同，因为本轮采用冻结最佳分类权重、额外去重和统一评估口径。第四代历史mAP已经逐位复现。

## 第一代78.30%与历史86.15%的来源

使用本轮同一COCO真值核验：原生官方NMS候选AP50为86.145559%，只裁图像边界后为86.145559%，再加入四代统一的跨类别IoU≥0.5额外去重后为78.301716%。第一代历史mAP已复现，差异来自后处理定义变化，并非训练退化。额外去重会移除部分重叠但定位更好的框，因此本轮统一后的AP可能更低。

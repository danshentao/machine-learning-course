# 自然场景鸟类识别 · 本地网站

网站地址： http://127.0.0.1:8765 。双击本目录的 `启动网站.cmd`，自动在后台启动服务并打开浏览器。关闭网页不会删除历史记录，也不会停止后台服务；双击 `停止网站.cmd` 停止服务（有识别任务时会提示等待）。

网站接入真实权重，不根据图片文件名、目录、XML或已保存的验证预测判断上传图片。所有识别图片、结果、日志及SQLite历史库保存在本目录 `data`；缓存位于E盘。网站服务与推理使用E盘RF-DETR工程的Python 3.11嵌入式运行时；Torch依赖复用E盘第三代项目共享包，旧Paddle包从第一代E盘site-packages单独载入，不重建或覆盖既有环境。

## 模型

- 第一代：PP-YOLOE-s 八类检测，读取第一代归档 `best_model_ap50.pdparams`，默认检测分数严格大于0.50。
- 第二代：原基准 PP-YOLOE+ bird 检测器，归档的 ResNet18 / 共享骨干 Bilinear CNN 最佳分类权重。可单选或两者对照；对照独立给出结果，不作概率融合。默认严格大于0.30。
- 第三代：相同原基准检测器 + 本地 BioCLIP 2 编码器 + 八类 `best_head.pt`，默认严格大于0.30。
- 第四代（默认）：已训练的 RF-DETR Small 单类 bird 检测器 + 与第三代完全相同的冻结 BioCLIP 2 编码器及八类线性分类头，默认严格大于0.30。RF-DETR 使用官方512输入和原图像素坐标输出；候选采用 score>0.001 的官方预测，再沿用同一套分数优先、非传递 IoU≥0.5 去重，阈值严格大于0.30后送入分类。分类外扩15%，采用 BioCLIP 2 官方 bicubic 预处理。结果JSON记录检测器哈希、分类器权重路径与全部分数。

2026-10-12 已恢复旧代 PP-YOLOE 和第二代 CNN 的 GPU 优先推理：Paddle 2.6.2 配套的 CUDA 11.8 / cuDNN 8 动态库现已可正常加载，移除了此前强制 CPU 的配置。默认有可用 CUDA 时使用 `gpu:0`，否则使用 CPU；可通过环境变量 `BIRD_PADDLE_DEVICE=cpu` 显式选择 CPU，或设为 `gpu` 要求 GPU。Paddle 与 Torch 在独立进程加载各自依赖，第四代检测和 BioCLIP 2 分类仍使用 CUDA。此前 CPU 推理记录与实验计时保留，不追溯修改。第四代实验指标、权重来源及 `树麻雀_08.jpg` 人工复核注记在“项目成果”资料列表提供。

前三代沿用各自配置的640检测输入。RF-DETR 使用实验验证的官方512预处理。所有检测框均按检测分数降序，只与已保留框比较，IoU≥0.5时隐藏低分候选，再应用模型各自默认阈值；不启用包含去重或框合并。二至四代均外扩15%，保持各自分类预处理（CNN整数裁剪与Bilinear缩放填充；BioCLIP floor/ceil裁剪、方形填充和官方Bicubic预处理）。

识别采用独立进程串行运行，模型每次加载，首次识别可能需要数十秒。历史保存检测阈值、候选与去重分组、八类分类分数、权重路径和日志。第一代没有独立分类头，分类得分栏显示“—”，不虚构八类softmax概率。

## 使用

上传JPG/PNG/WEBP/BMP（≤20MB，≤2000万像素），默认使用第四代，也可切换前三代，点击“识别图片”。结果分别显示检测分数和分类分数，可展开查看全部八类得分；可开关框线、放大、下载带框图片和结果JSON；历史条目可重新查看。“模型对照”介绍四代流程，“项目成果”展示第四代固定验证指标与实验资料。

图片存为经EXIF方向校正的RGB PNG，保留原上传文件名作显示。一次最多等待5条任务；只有运行成功的结果才标记完成，失败时保留日志。本次关闭服务期间未完成的记录在重启时标记中断，不假装完成。

仅监听本机127.0.0.1，不能让其他电脑直接访问。不上传云端，不调用外部API。不要使用任意公共反向代理直接公开本服务。

## 局限

只识别课程八类，未实现未知物种拒识。背景、遮挡、小目标以及八类之外的物种可能产生错误，置信分数不是正确率，零框不证明没有鸟。项目成果指标来自反复用于选权重与探索的172张验证图，不代表外部图片或独立测试成绩。

不修改原图、XML、旧预测或权重。D组未训练，DINOv3未接入。所有新增内容在E盘；停止网站不影响原实验工程。
